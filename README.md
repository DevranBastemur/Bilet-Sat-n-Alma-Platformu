🚌 Otobüs Bileti Rezervasyon Sistemi

Bu proje, PHP tabanlı basit bir otobüs bileti rezervasyon uygulamasıdır.
Kullanıcıların otobüs seferlerini görüntüleyip koltuk seçerek bilet oluşturabildiği bir sistem sunar. Proje, Docker kullanılarak hızlı ve kolay şekilde konteyner ortamında çalıştırılabilir.

🚀 Özellikler

👤 Kullanıcı kayıt ve giriş sistemi

🚌 Otobüs seferlerini listeleme

💺 Koltuk seçimi ve bilet oluşturma

🛠️ Admin paneli ile sefer yönetimi

🗄️ SQLite veritabanı desteği

🐳 Docker ile kolay kurulum

🌐 Apache + PHP altyapısı

🧰 Kullanılan Teknolojiler

PHP 8.2

Apache Web Server

SQLite

Docker & Docker Compose

HTML / CSS / JavaScript

🐳 Docker ile Çalıştırma

Projeyi Docker ile çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

# 1️⃣ Proje dizinine gidin
cd otobus-bileti

# 2️⃣ Docker container'ını build edip başlatın
docker compose up --build

Kurulum tamamlandıktan sonra uygulamaya aşağıdaki adresten erişebilirsiniz:

http://localhost:8080
📌 Not

Bu proje öğrenme ve geliştirme amacıyla hazırlanmış örnek bir rezervasyon sistemidir. Gerçek üretim ortamlarında kullanılmadan önce güvenlik ve performans iyileştirmeleri yapılması önerilir.
